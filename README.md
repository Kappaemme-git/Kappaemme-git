## Currently building: VibeDesk

[VibeDesk](https://www.vibedesk.online/) is a browser-based workspace for focused work. It brings a Pomodoro timer, visual scenes, music, ambient sounds, notes, tasks, and progress tracking into one tab.

I started VibeDesk in November 2025 as an independent project. I'm actively building and improving it in public.

**[Try the live app](https://www.vibedesk.online/)** · **[Explore the source](https://github.com/Kappaemme-git/Vibedesk-2.0)** · **[Read about the project](https://www.vibedesk.online/about.html)**
